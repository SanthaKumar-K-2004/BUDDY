## 1. Architectural Overview

Phase 7 establishes a **Local-First Personal Web Intelligence and Adaptive Control Engine** operating natively inside the browser extension without remote servers, paid databases, or third-party profiling. It consumes real normalized browser activity signals generated by Phase 0–6 systems, analyzes behavior locally, computes rolling personal baselines, extracts factual insights, and executes transparent, explainable policies.

## 2. Core Modules & Directory Layout

### 2.1 Monorepo Workspace: `packages/intelligence-engine`

- [packages/intelligence-engine/src/pattern-detector.ts](file:///home/santhakumar/Desktop/BUDDY/packages/intelligence-engine/src/pattern-detector.ts): Detects factual, objective browsing patterns:
  - **Rapid Reopens**: Same site visited repeatedly within short intervals (<= 3 minutes).
  - **Frequent Site Switching**: Alternating between distinct social/entertainment domains within a 5-minute sliding window.
  - **Long Uninterrupted Sessions**: Active sessions exceeding the continuous engagement threshold (e.g. >= 45 minutes).
  - **Repeated Short-Form Content**: Elevated velocity and high session counts on short-form media (Reels, Shorts, TikTok).
  - **Late-Session Browsing**: Activity occurring between midnight and 05:00 AM local time.
- [packages/intelligence-engine/src/trend-engine.ts](file:///home/santhakumar/Desktop/BUDDY/packages/intelligence-engine/src/trend-engine.ts): Computes statistical trends and rolling averages:
  - **Personal Baselines**: Computes mean daily usage across historical windows (7-day, 14-day, 30-day).
  - **Insufficient Data Guard**: Strictly displays "Not enough data yet" when fewer than 2 active days exist.
  - **Period-over-Period Comparisons**: Accurately computes absolute delta and percentage changes between current and previous periods.
  - **Time-of-Day Bucketing**: Partitions usage into Morning (06–12), Afternoon (12–17), Evening (17–22), and Night (22–06) using local timezone arithmetic.
  - **Day-of-Week Distribution**: Measures daily activity across Monday through Sunday.
- [packages/intelligence-engine/src/insight-engine.ts](file:///home/santhakumar/Desktop/BUDDY/packages/intelligence-engine/src/insight-engine.ts): Fact-based, explainable insight synthesizer:
  - **Strict No-Diagnosis Invariant**: Forbids medical/psychological labeling (e.g., ADHD, addiction, depression).
  - **Evidence Provenance**: Every insight includes an `evidence` array detailing exact measured minutes, counts, or dates.
  - **Deterministic Priority**: Assigns `high`, `medium`, or `low` priority based on actionable relevance.
  - **AI Hallucination Protection**: Verifies any external or model-generated claim against real recorded metrics before presenting it to the user.
- [packages/intelligence-engine/src/adaptive-policy-engine.ts](file:///home/santhakumar/Desktop/BUDDY/packages/intelligence-engine/src/adaptive-policy-engine.ts): Deterministic policy evaluation and adaptation:
  - **Deterministic Policy Priority Hierarchy**:
    1. Emergency Override (`emergency_override`)
    2. Family & Parental Policy (`family_policy`)
    3. User Explicit Block (`user_block`)
    4. Focus Mode Enforcement (`focus_mode`)
    5. Daily / Category Limit (`daily_limit`)
    6. Smart Break Prompt (`smart_break`)
    7. Neutral Suggestion (`suggestion`)
  - **Transparent Adaptation**: Limits are NEVER altered silently; automatic adaptation requires explicit user opt-in (`isAdaptiveLimitsEnabled: true`).
  - **Immutable Decision Log**: Records timestamp, action, trigger, policy source, and human-readable explanation in local storage.
- [packages/intelligence-engine/src/smart-coach.ts](file:///home/santhakumar/Desktop/BUDDY/packages/intelligence-engine/src/smart-coach.ts): Context-aware break coaching:
  - Tracks continuous active minutes without forced lockouts by default.
  - Detects natural rest intervals (idle gaps >= 5 minutes) and resets continuous active counters.
  - Manages prompt cooldowns to prevent notification fatigue.
- [packages/intelligence-engine/src/notification-manager.ts](file:///home/santhakumar/Desktop/BUDDY/packages/intelligence-engine/src/notification-manager.ts): Anti-spam notification controller:
  - Implements per-type cooldown windows (e.g., 30 minutes for break prompts).
  - Deduplicates identical message payloads within short intervals.
  - Respects quiet hours (e.g., 22:00 to 07:00).
- [packages/intelligence-engine/src/data-pipeline.ts](file:///home/santhakumar/Desktop/BUDDY/packages/intelligence-engine/src/data-pipeline.ts): Pipeline integrity & privacy controls:
  - Validates event timestamps, bounds, and structures.
  - Deduplicates incoming events using composite keys (`site:tabId:timestamp`).
  - Complete JSON export and total privacy data reset.

## 3. Data Contracts & Storage Schema

Defined in `@buddy/shared-types` and stored in `chrome.storage.local`:

```ts
export interface Insight {
  id: string;
  type: InsightType;
  priority: InsightPriority;
  title: string;
  message: string;
  evidence: string[];
  suggestedAction?: InsightAction;
  timestamp: number;
  dismissed: boolean;
}

export interface BehavioralPattern {
  id: string;
  type: PatternType;
  confidence: number;
  occurrences: number;
  firstObserved: number;
  lastObserved: number;
  evidence: string[];
  metadata?: Record<string, unknown>;
}

export interface AdaptivePolicyConfig {
  isAdaptiveLimitsEnabled: boolean;
  adaptiveLimitBufferMinutes: number;
  smartBreaksEnabled: boolean;
  continuousActivityThresholdMinutes: number;
  breakDurationMinutes: number;
  breakReminderCooldownMinutes: number;
  quietHoursStart: number;
  quietHoursEnd: number;
}

export interface PolicyDecisionLog {
  id: string;
  timestamp: number;
  action: 'block' | 'warn' | 'allow' | 'suggest_break';
  trigger: string;
  policy: string;
  result: 'enforced' | 'suggested' | 'bypassed';
  explanation: string;
}
```

## 4. Background Service Worker & Dashboard Integration

### 4.1 Service Worker (`apps/buddy-focus/entrypoints/background.ts`)
- Subscribes to `ACTIVITY_EVENT` messages from content scripts.
- Feeds validated events into `LocalDataPipeline`, updates continuous active counters in `SmartCoach`, and runs debounced pattern detection.
- Periodically evaluates daily trends and generates fact-based insights.
- Handles extension messaging for insight retrieval, dismissal, configuration updates, and full privacy data reset.

### 4.2 Dashboard Insight Center (`apps/buddy-dashboard`)
- New **Insights Screen** (`InsightsScreen.tsx`) added to the primary navigation bar.
- Renders:
  - **Active Insights**: Filterable cards displaying title, message, evidence list, and one-click actions.
  - **Behavioral Patterns**: Real detected activity patterns (rapid reopens, high switching, late browsing) with evidence.
  - **Personal Baselines & Trends**: 7-day average, period deltas, top category breakdown, and time-of-day distributions.
  - **Policy Decision Audit Log**: Recent deterministic policy enforcements with timestamp and explanation.
  - **Adaptive Control Settings**: Opt-in toggle for adaptive limits, smart break threshold slider, and quiet hours.

## 5. Security & Privacy Guarantees

1. **Zero External Network Requests**: No calls to external analytics endpoints, servers, or cloud databases.
2. **Zero Sensitive Data Ingestion**: No tracking of keystrokes, form inputs, passwords, authentication tokens, or private messages.
3. **Deterministic Evaluation**: No stochastic AI models directly executing enforcement or mutating policies.
4. **Transparent Adaptation**: Every change to limits or rules is auditable, explainable, and under user control.
5. **Full Privacy Control**: Users can export their complete analytics dataset as JSON or perform a complete one-click data wipe.
