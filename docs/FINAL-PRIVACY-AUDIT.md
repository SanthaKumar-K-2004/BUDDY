## 2. Data Minimization Principles

1. **Host-Level Only:** Buddy tracks `youtube.com`, `instagram.com`, etc., but deliberately strips query parameters, search queries, channel IDs, and video URLs.
2. **Local Vault Boundary:** All metrics exist solely in local browser sandbox storage. If the user uninstalls the extension or clears browsing data, all data is instantly and permanently destroyed.
3. **Parental Privacy Protection:** The Family module monitors category flags on-device without logging private chat messages, emails, or personal correspondence.
